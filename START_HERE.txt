🚀 QUICK START GUIDE
====================

STEP 1: Install Dependencies
-----------------------------
cd multilingual-transcriber
pip install -r requirements.txt

⏱️  First installation: 5-10 minutes
💾 Downloads: ~500MB (PyTorch, Transformers, etc.)

STEP 2: Install FFmpeg (Audio Support)
---------------------------------------
Windows (Chocolatey):  choco install ffmpeg
macOS (Homebrew):      brew install ffmpeg
Linux (apt):           sudo apt-get install ffmpeg

STEP 3: Test Installation
--------------------------
python main.py test

Expected output:
  ✓ PyTorch
  ✓ Whisper
  ✓ Pyannote
  ✓ Transformers
  ✓ Pydub

STEP 4: Run First Transcription
--------------------------------
python main.py sample.wav

This will:
  📥 Download Whisper Large V3 (~3GB) on first run
  🗣️  Transcribe audio
  👥 Identify speakers (requires HuggingFace auth)
  🌐 Translate to English
  📄 Save JSON, Markdown, SRT, TXT

📊 MODEL DETAILS
================

Whisper Models (Speech Recognition):
  tiny    : ~75MB   | Fastest  | Low accuracy
  base    : ~150MB  | Fast     | Medium accuracy
  small   : ~500MB  | Fast     | Good accuracy
  medium  : ~1.5GB  | Moderate | Very good accuracy
  large   : ~3GB    | Slow     | Excellent accuracy
  large-v3: ~3GB    | Slow     | Best accuracy (DEFAULT)

Pyannote (Speaker Diarization):
  speaker-diarization-3.1 : ~1GB | State-of-the-art

Translation Models:
  Helsinki-NLP/opus-mt-*-en : ~500MB each
  • On-demand download per language
  • Cached after first use

🐛 TROUBLESHOOTING
==================

❌ "ModuleNotFoundError: No module named 'pydub'"
   → pip install -r requirements.txt

❌ "FFmpeg not found"
   → Install FFmpeg (see STEP 2 above)

❌ "CUDA out of memory"
   → Use smaller model: --model medium
   → Or use CPU: --device cpu

❌ "Pyannote authentication failed"
   → Visit: https://huggingface.co/pyannote/speaker-diarization-3.1
   → Accept terms, then: huggingface-cli login
   → Or skip: --skip-diarization

❌ "ImportError: torch"
   → pip install torch torchaudio --index-url https://download.pytorch.org/whl/cu118
